# 📋 Zapols Kitchen — WhatsApp Phone Order Template

When a customer calls your phone to order food, copy and paste this template into WhatsApp. Fill in the blanks, then send it to the customer or pin it to the Kitchen Board.

---

## ✅ Template (Copy & Paste This)

```
🍲 *Zapols Restaurant & Lounge*
*Phone Order Ticket*
------------------------------
*Customer:* [Name]
*Location/Time:* [Floor / Desk / Pickup Time]
*Order ID:* #ZPL-[type 3 random letters]
*Pickup Code:* [tell them a 4-digit code e.g. 4832]
------------------------------
• [Qty]x [Item] — ₦[Price]
• [Qty]x [Item] — ₦[Price]
• [Qty]x [Item] — ₦[Price]
------------------------------
*Packaging:* Takeaway pack (+₦300) / Own plate (₦0)

------------------------------

```

## 🔑 Quick Tips

1. **Tell them the pickup code immediately on the call** — e.g. *"Your code is 4-8-3-2, write it down."*
2. **Paste this into the Kitchen Board** after hanging up → it automatically extracts name, items, total, and code.
3. **Or use the in-app 📞 Phone Order button** on the Kitchen Board — it does all of this for you automatically with a food picker, auto-totals, and instant code generation.
